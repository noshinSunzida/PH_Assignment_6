Project Name: FitLog



Description: 

Fit Log is a Next.js based workout tracking application. Users can explore different workouts, view exercise details, and organize their daily workout plans. The project is built using Next.js, TypeScript, Tailwind CSS and DaisyUI with a responsive user interface.



Used Technologies:

Next.js 15
Context API
TypeScript
Tailwind CSS
React Toastify



5 Features:

* Different workouts can be explored with detailed information.

* Workouts can be added to Today's Plan or Saved for Later.

* Duplicate workouts are prevented across both lists.

* Workout lists can be sorted by duration, rating, and calories.

* Daily workout progress can be tracked through exercise, time, and calorie summaries.
